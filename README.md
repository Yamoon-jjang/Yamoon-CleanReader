# 야문 클린리더

흐트러진 텍스트(TXT) 파일의 문단을 읽기 좋게 정리하고, 정리한 글을 책처럼 편하게 읽는 Windows 프로그램입니다.
설치 없이 exe 하나로 실행됩니다.

## 주요 기능

- **문단 정리** — 옛 모바일용 고정폭 글, 한 줄로 이어진 글, 쓸데없이 많은 줄바꿈을 찾아 문단을 되살립니다.
- **문장 나누기** — 문장마다 줄을 나누되, 말줄임표 · 문장 속 인용 · 괄호 안에서는 나누지 않습니다.
- **대사 인식** — 여러 줄에 걸친 대사를 한 덩어리로 묶고, 대사 앞뒤를 보기 좋게 띄웁니다.
- **제목 · 장면 전환 · 시 · 목록 보존** — 장 제목, 장면 구분, 작가가 일부러 짧게 끊은 시 · 편지, 대화 기록 같은 목록형 글을 망가뜨리지 않습니다.
- **한국어 다듬기** — 띄어쓰기 · 문장부호 정리, 전각→반각, 괄호 속 한자 제거, 자모 분리 복구.
- **읽기 모드** — 글꼴 · 크기 · 색 · 바탕색 · 줄 간격 · 여백을 바꾸고, 클릭으로 쪽을 넘기며, 읽던 위치를 기억합니다.
- **찾기 · 바꾸기**, 여러 파일 한꺼번에 정리, 다양한 인코딩(UTF-8 · CP949 등)과 옛 `.cap` 파일 지원.
- **원본 보호** — 원본은 바꾸지 않고 `_정리.txt`로 따로 저장합니다. 글 속의 보이지 않는 서식 문자도 손대지 않고 그대로 보존합니다.

## 내려받기와 실행

1. **Releases**에서 최신 zip을 받아 원하는 폴더에 풉니다.
2. `YamoonCleanReader.exe`를 실행합니다. Windows "PC 보호" 창이 나오면 **추가 정보 → 실행**을 누릅니다(코드 서명이 없는 개인 제작 프로그램이라 나오는 안내입니다).

자세한 사용법은 함께 들어 있는 `README.txt`를 보세요. 지원: Windows 7 이상 (64비트)

## 소스에서 빌드하기

C++17 / Win32 API로 작성했으며 MinGW-w64 GCC 13(win32 스레드 방식)으로 빌드합니다. 명령은 [BUILD.txt](BUILD.txt)에 있습니다.
GitHub Actions(`.github/workflows/build.yml`)가 같은 명령으로 빌드하고, 가져오는 DLL · 보안 플래그 · 버전 정보를 검사합니다.
